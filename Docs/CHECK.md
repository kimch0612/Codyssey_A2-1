# A2-1 구현 체크리스트

근거 문서: `Docs/subject.txt`, `Docs/evaluate.txt`

- 진행 방식: Claude가 구현하고, **구현 후 실행으로 검증된 항목만 체크**한다. 설계만 정했거나 틀만 만든 것, 문서를 쓴 것은 체크하지 않는다. 커밋은 사용자가 한다.
- 단위마다 "수학 레슨 → 이해 확인 → 계획·컨펌 → 구현 → 인계" 순서로 진행한다(내 설계 선택).
- 보너스 과제는 제외한다.
- 명세가 요구하지 않는 파일명·클래스 구성은 강제하지 않는다.
